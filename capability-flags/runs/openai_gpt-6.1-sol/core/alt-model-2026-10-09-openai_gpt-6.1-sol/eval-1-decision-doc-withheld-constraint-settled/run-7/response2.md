The test is whether a future reader would need the full competing tradeoffs to understand—or avoid reversing—the choice, rather than how difficult the decision felt. GaugeDesk already requires local-file lookups with no runtime network access, which rules out the HTTPS directory and managed service as described.

The registry row captures the remaining tradeoff: SQLite gives predictable offline lookups without a service, while each kiosk takes responsibility for validation and index rebuilding. A standalone decision doc would largely repeat that rationale.
