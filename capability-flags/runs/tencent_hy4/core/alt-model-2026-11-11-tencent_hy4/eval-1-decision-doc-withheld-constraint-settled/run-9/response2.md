The earns-its-place test runs from the **landed state**, not the deliberation. Two things disqualify this choice:

- **An inherited constraint settles it.** "No runtime network access is permitted" makes the HTTPS-directory and managed-search options inadmissible before any criterion gets weighed. Three "close" options, one admissible — you went back and forth because the tenet wasn't being applied, not because the options were comparable.
- **It affects only its own node.** Certificates keep the same result and interface; no other design node is sized around the outcome.

The skill is explicit: don't offer a doc for a choice an inherited constraint settles or one confined to its own node, *"however long the debate ran."* "I went back and forth" is named as a **symptom, not the test** — a directory full of decision docs is a smell, and a doc here would freeze a false three-way trade-off into permanent intent.

So the Decisions & Alternatives row already in the LLD is the right home: it answers the one question a cold reader has ("why SQLite?") in one line. A full doc is exactly the residue *docs carry current intent* strips.
