SHEET-MARK-READBACK-001: The Positions tab renders one row per symbol (identity), keying the mark read-back settle pass by row order (symbol). The invariant is enforced defensively: `render_positions` asserts via `BTreeSet` that each symbol appears exactly once. Violation (a symbol rendered twice from an unknown future non-Map source) returns `ViewError::DuplicateSymbolRow(symbol)` loudly. The real API (`Snapshot.positions` is `Map<Symbol,_>`) guarantees uniqueness by construction; the guard remains as a cascade safeguard if a future refactor breaks that contract.

SHEET-MARK-READBACK-002: The settle pass (`read_marks`) polls for price readings on the symbol list passed by the caller. The symbols slice is the authority for the expected Positions tab symbols; the pass reads symbol by symbol from `PricePass` (the result of `client.read_price_pass()`), keying by exact symbol match. A symbol absent from a poll pass is treated identically to a transient reading (polling continues).

SHEET-MARK-READBACK-003: Transient readings (GOOGLEFINANCE `#N/A` or `Loading...`) carry the prior good cached mark forward if one exists, preserving the last-known price rather than nulling a live position. A symbol with no prior mark that stays transient past the bounded window (default 8 polls) degrades as `DegradeReason::TimedOut` (no mark). If a symbol returns a permanent terminal error (bad ticker format), it degrades as `DegradeReason::Permanent` (no prior carry forward, mark is absent).

SHEET-MARK-READBACK-004: Numeric price readings are converted to `Cents` via `price_to_cents(price_usd: f64) -> Result<Cents, DegradeReason>`. A positive price that rounds to 0¢ after `round_half_to_even(price × 100)` degrades as `DegradeReason::SubCent` (anomaly, not a real zero mark). Non-finite prices (`NaN`, `±∞`) degrade as `DegradeReason::Permanent`. A numeric reading that successfully rounds to a positive `Cents` value is paired with its GOOGLEFINANCE quote date (`Date` epoch: days since 1970-01-01) and recorded as a good mark in `MarksProduced.marks`.

SHEET-MARK-READBACK-005: The settle pass polls with a bounded retry window (`SettleConfig.max_polls`, default 8). Settlement exits early if all requested symbols are numeric-or-terminally-errored (settled state), or after the window elapses. A still-transient or absent symbol at exit carries its prior mark (if any); otherwise degrades `TimedOut`.
