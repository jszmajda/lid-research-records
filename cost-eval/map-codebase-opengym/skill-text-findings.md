# What the review of draw 1 found in `/map-codebase`'s own text

The review of draw 1 (the set-aside draw) ends with a section headed "Inconsistencies inside the skill that the run exposed". It lists eleven places where the skill's own documents contradict each other or leave a gap, and says they "are about LID v1.4.6, not about the run". They come from reading the skill's files side by side. The run showed where they matter, but none of them depends on the harness leak that set draw 1 aside, which touched only what the map said about the project's exercise media.

The review didn't open the list of dependencies or the coverage measurements, so it wasn't shaped by them. It is a local record, `runs/analysis/opengym/map-review.md`, lines 138 to 152 of the notebook's `docs/research/cost-eval/`. It quotes the map and the run's transcripts, so it isn't published; this file restates its last section against the skill's public text.

**The text checked.** LID 1.4.6, the release every draw ran. The skill's files are the same on `main` today: between the `v1.4.6` tag and `main`, nothing in `plugins/arrow-maintenance/skills/map-codebase/` changed except its evals file. Links below go to the tag, at the lines quoted.

- `SKILL.md`: [plugins/arrow-maintenance/skills/map-codebase/SKILL.md](https://github.com/jszmajda/lid/blob/v1.4.6/plugins/arrow-maintenance/skills/map-codebase/SKILL.md)
- The reference: [references/brownfield-bootstrap.md](https://github.com/jszmajda/lid/blob/v1.4.6/plugins/arrow-maintenance/skills/map-codebase/references/brownfield-bootstrap.md), which calls `SKILL.md` "the canonical phase structure" (line 7)
- The survey worker's template: [references/subagent-sweep-prompt.md](https://github.com/jszmajda/lid/blob/v1.4.6/plugins/arrow-maintenance/skills/map-codebase/references/subagent-sweep-prompt.md)

**What happened to each.** Each finding was rechecked against that text for this record. Ten hold, and they're filed as LID issues: eight in [#133](https://github.com/jszmajda/lid/issues/133) and two in [#134](https://github.com/jszmajda/lid/issues/134). The eleventh doesn't hold and wasn't filed.
